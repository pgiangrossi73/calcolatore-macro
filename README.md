# Calcolatore Macro

Web app installabile (PWA) per il piano dei pasti, il diario alimentare e il bilancio della giornata.

- Apri il sito con Chrome su Android e scegli **Installa app** (o menu ⋮ → *Aggiungi a schermata Home* → *Installa*).
- Funziona offline dopo la prima apertura.
- Profilo, diario e libreria restano nel telefono (localStorage): in questo repository c'è solo il codice.
- Per pubblicare un aggiornamento: sostituisci `index.html` e cambia `VERSION` in `sw.js`.

Specifica completa: `calcolatore-macro.md` nel progetto Claude "Calcolatore Macro".
